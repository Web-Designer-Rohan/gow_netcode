# Custom GoW Netcode Signaling & Proxy Bridge

An experimental open-source WebSocket signaling server and network proxy architecture designed to explore multiplayer state synchronization frameworks.

## Project Structure
- `server/net_server.py`: Asynchronous WebSocket relay server for client delta packets.
- `server/test_client.py`: Socket client script for testing multi-instance communication.
- `hooks/`: C++ memory hook stubs and header templates.
